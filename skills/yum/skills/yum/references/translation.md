# Reference translation

## Transfer by dimension

| Dimension | Extract | Decide for this product |
|---|---|---|
| Layout | Hierarchy, grouping, content order, alignment relationships | Content-driven widths, real labels, responsive collapse, existing navigation |
| Typography | Roles, contrast between headings and text, density | Available fonts, token scale, readable wrapping, actual font rights |
| Colour | Surface, text, accent, selected, error roles | Map to existing tokens; measure contrast in the implemented combinations |
| Motion | Cause, trigger, moving object, endpoint | Stack-appropriate implementation, interruption, input parity, reduced motion |
| Flow | Decision sequence and visible recovery | Required identity, payment, consent, and error states; do not import the competitor's policy |
| Copy | Function of a label, reassurance, or proof block | Accurate product claims and the user's voice; no invented customer metrics |
| Imagery | Composition, focal point, treatment | Supplied or appropriately sourced assets and target crops |

Screenshots support relative appearance, not exact CSS values or hidden behaviour. Use exact values when supplied or measured; otherwise choose target values and identify them as implementation decisions.

## Match the deliverable

- **Landing page:** build the requested sections using real content. Inspect narrow and wide layouts, CTA destinations, long copy, and media loading.
- **App flow:** map every required step and state before styling. Exercise transitions, recovery, keyboard/touch paths, and existing purchase or account contracts where applicable.
- **Portfolio:** use the user's own work, role, and evidence. Reference structure can guide a story; it cannot supply missing achievements.
- **OG/social assets:** confirm the target canvas and supplied brand assets. Inspect crops and text at realistic preview size. Export every requested asset separately; list actual saved paths.
- **Component:** preserve documented semantics and project conventions. Inspect interactive states and content extremes instead of matching only the default frame.
- **Motion:** observe a recording or live interaction before claiming a match. Check the same trigger and final state with motion reduced; visual resemblance alone does not establish equivalent control.

## Handoff record

Keep source URL/file, creator when known, adopted feature, target change, and checks. This can be a few lines in the final handoff; do not create a research folder or publish someone else's captures unless the task calls for it.

Three references do not confer reuse rights. Conversely, a supplied authorised design does not require changing its identity merely to appear original. Match the brief and the asset permissions actually available.
