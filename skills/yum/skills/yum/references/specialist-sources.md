# Specialist sources

Use only when the main router leaves a gap. These are candidate destinations from the source material, not a guarantee of current access or coverage. Verify the relevant page before recommending a purchase or claiming to have inspected an item.

| Need | Candidates | Inspect for |
|---|---|---|
| Designer portfolios and case studies | [Bestfolios](https://www.bestfolios.com/), [Wall of Portfolios](https://www.wallofportfolios.in/), [Pafolios](https://pafolios.com/) | Work index, narrative, role and outcome evidence; visit the designer's actual site |
| Broader landing-page search | [Lapa Ninja](https://www.lapa.ninja/), [One Page Love](https://onepagelove.com/), [SaaS Landing Page](https://saaslandingpage.com/) | Relevant page types; distinguish live-site entries from templates |
| Mobile alternatives | [Pttrns](https://pttrns.com/), [UI Sources](https://www.uisources.com/) | Platform, task, capture age, and available sequence; verify current branding and coverage |
| More editorial web work | [Httpster](https://httpster.net/), [Godly](https://godly.design/) | Type and layout direction; resolve current URLs rather than assuming affiliation with another gallery |
| Identity and type context | [Brand New](https://www.underconsideration.com/brandnew/) | The author's critique and the actual identity work; distinguish opinion from product evidence |
| Official design systems | [Design Systems Repo](https://designsystemsrepo.com/) | Links to primary component documentation |
| Motion implementation | [Codrops](https://tympanus.net/codrops/), [Motion UI](https://motion.dev/ui/) | Mechanism and implementation constraints; verify demo licences and dependencies before reuse |
| Conceptual art direction | [Dribbble](https://dribbble.com/), [Behance](https://www.behance.net/) | Visual ideas and creator attribution; do not assume a posted concept shipped or performed well |
| Templates and component kits | [Landingfolio](https://www.landingfolio.com/), [Untitled UI](https://www.untitledui.com/) | Whether the item is an inspiration entry or a reusable asset, and the applicable licence |

A studio's own site can be a valid reference even though it is not a library. Prefer the user-supplied source when it answers the brief. Research quality depends on relevant inspected evidence, not membership in this list.
